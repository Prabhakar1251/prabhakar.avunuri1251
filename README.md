## 🚀 Run Locally

This is a static website and does not require a build process or package installation.

1. Clone or download this repository.
2. Open the repository folder.
3. Open `index.html` in your browser.

Alternatively, use **Visual Studio Code** with the **Live Server** extension to preview the site locally.

## 🌐 Publish with GitHub Pages

1. Push `index.html` and `README.md` to your GitHub repository.
2. Open the repository on GitHub and go to **Settings → Pages**.
3. Under the build and deployment section, choose **Deploy from a branch**.
4. Select your branch (usually `main`) and the root folder (`/`), then save.
5. After GitHub Pages finishes publishing, open the URL shown in the Pages settings.
